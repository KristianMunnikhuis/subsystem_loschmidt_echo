\section{Landau-Zener Solution to Kibble-Zurek Scaling}
This section comes directly from "Dynamics of a Quantum Phase Transition: Exact Solution in Quantum Ising model"


The time depednent equations for the TFIM reduce to 

\begin{equation}
    i \hbar \frac{d u_k}{d\tau } = 
    -\frac{1}{2} ( \tau \Delta_k) u_k + \frac{1}{2}v_k
\end{equation}
\begin{equation}
    i \hbar \frac{d v_k}{d\tau } = 
    +\frac{1}{2} ( \tau \Delta_k) v_k + \frac{1}{2}u_k
\end{equation}

Here, $\tau$ depends on the time $t$ and the quench protocol, while $\Delta_k$ is the gap parameter for mode $k$. The functions $u_k(\tau)$ and $v_k(\tau)$ describe the time evolution of the Bogoliubov quasiparticle amplitudes for each momentum mode $k$.

We can define them as follows:

\begin{equation}
    \Delta_k ^{-1} = 4 J \tau_Q \sin^2(ka)
\end{equation}
\begin{equation}
    \tau = 4 J \tau_q \sin(ka)(\frac{t}{\tau_Q}+\cos(ka))
\end{equation}

This can be solved by first recognizing that only modes iwth small energy contribute in the limit of a large quench: 
\begin{equation}
    |ka| < \frac{\pi}{4}
\end{equation}

For these modes we may use the LZ formula for excitation probability:

\begin{equation}
    p_k \approx e^{-\frac{\pi}{2 \hbar \Delta_k}}
\end{equation}

This is valid when

\begin{equation}
    ka = (4 \pi J \tau_Q / \hbar )^{-\frac{1}{2}} << \frac{\pi}{4}
\end{equation}

or equivalently, when 

\begin{equation}
    \tau_Q >> \frac{4\hbar }{\pi^3 J}
\end{equation}

From which we then derive the number of kinks $\mathcal{N}$ or the defect density $$n = \frac{\mathcal{N}}{N}$$

\begin{equation}
    n = \lim_{N \to \infty} \frac{\mathcal{N}}{N} = \frac{1}{2\pi} \int ^{\pi}_{\pi} d(ka) p_k = \frac{1}{2\pi} \frac{1}{\sqrt{2J \tau_Q/\hbar}}
\end{equation}

It should be noted that this calculation of defect density provides $O(1)$ corrections to the formula suggested by Zurek. The real highlight is the prediction of power law scaling of defect density and $\tau_Q$:

$$n \propto \tau_Q^{-\frac{1}{2}}$$

The paper also points out that for a finite chain we can also predict the fastest $\tau_Q$ that no particles get excited (which can be done becuase a finite chain is gapped).

This quantitiy is given as 
\begin{equation}
    \mathcal{P}_{GS} = \prod_{k>0} (1-p_k)
\end{equation}

Only the $\frac{\pi}{N}$ pair is likely to be excited (Question: Why?) so we can approximate that 

\begin{equation}
    \mathcal{P}_{GS} = 1- p_{\frac{\pi}{N}} \approx 1 - \exp(-2 \pi^3 \frac{J \tau_Q}{\hbar N^2})
\end{equation}

So we can estimate that an adiabatic quench occurs when 

$$\tau_Q > \tau_Q^{ad} = \frac{\hbar N^2}{2 \pi^3 J}$$

Inverting this relationship tells us that the size $N$ of a defect free chain grows as $\tau_Q^{\frac{1}{2}}$


\subsection{Ferromagnetic to Paramagnetic}

The previous section was for a disordered to ordered quench. Now, we can analyze the opposite.

We can assume the value of $g$ to be of the form 

$$g(t>0) = \frac{t}{\tau_Q}$$ 

and that when $g=0$ we are in the even parity groundstate.

In the $g>1$ groundstate limit we expect all spins to be in the $+x$ orientation, so we may define ground state fidelity as 

\begin{equation}
    \mathcal{F} = \frac{1}{2}(N - \sum _{n+1}^{N} \sigma^x_n)
\end{equation}

when $g>>1$ the hamiltonian reduces to $$H \approx -Jg \sum^N_{n=1} \sigma^x_n = -Jg(N-2\mathcal{F})$$

At the same time, 

$$H^{+} \approx 2Jg\sum_k \gamma^\dagger_k \gamma_k - JgN$$

so we can recognize via inspection that 

$$\mathcal{F} = \sum_k \gamma_k^\dagger \gamma_k$$

which allows us to predict that defect density is the same, 

\begin{equation}
    f = \frac{1}{2\pi} \frac{1}{\sqrt{2 J \tau_Q /\hbar}}
\end{equation}

\section{Equilibrium Scaling exponents of Projector Operators}

For this section, we will slightly modify the hamiltonian by rotation. The underlying physics will remain the same.

\begin{equation}
    \hat{H} = -J \sum_{i=1}^{L} \sigma^{x}_{i} \sigma^{x}_{i+1} -h \sum_{i=1}^{L} \sigma^{z}_{i}
\end{equation}

Now we will discuss the scaling exponents of the projector operators. We approach this problem in the even parity sector so odd numbers of spin operators give 0 (e.g. $\braket{\sigma_x}=0$)

For starters, we can look at $P_2$:

\begin{equation}
    \braket{P_2} = \frac{1}{4N} \sum_{i=1}^{L} (\braket{1} + \braket{\sigma^x_i \sigma^{x}_{i+1}}) \approx \frac{1}{4}+\frac{ 
        \braket{{\sigma^x_0 \sigma^{x}_{1}}}}{4}
\end{equation}

and how it is expected to scale near the critical point assuming the thermodynamic limit. Also, assuming PBC then the last approximate equality turns into an exact equality.

\subsection{$n$-point correlation functions}


Correlations of the form $\braket{\sigma^x_0 \sigma^x_n}$ are computed using pfaffians of the fermionic operators. For instance, we can define 
\begin{equation}
    A_i = c^\dagger_i+c_i
\end{equation}

and 

\begin{equation}
    B_i = c^\dagger_i - c_i
\end{equation}

We can use the definition of $\sigma^x$ in terms of fermionic creation and annihilation operators to write out the expression

\begin{equation}
    \braket{\sigma^x_0 \sigma^x_n } = \braket{\mathbf{B_0}A_{1}B_{1}...A_{n-1}B_{n-1}\mathbf{A_n}}
\end{equation}

In the above expression I bold the first and last majorana fermionic operators to emphasize the structure of the correlation functions. The internal structure comes from the nature of the Jordan-Wigner strings that must attach the two operators.

It can be shown through the definition of the operators that 

\begin{align}
    \braket{A_i A_j} &= \delta_{ij} \\
    \braket{B_i B_j} &= -\delta_{ij}   
\end{align}

and that consequently the only "interesting" correlations will be of the form
\begin{equation}
    \braket{B_i A_j} = -\braket{A_j B_i} = D_{i-j+1}
\end{equation}

There are a few different ways at approaching the calculation of $D_n$. I cite the solution given by Sachdev:

\begin{align}
    D_n &= \int_{0}^{2\pi} \frac{d\phi}{2\pi} e^{-in\phi} \tilde{D}(e^{i\phi}) \\
    \tilde{D}(z= e^{i\phi}) &= \left( \frac{1 - g z}{1 - \frac{g}{z}} \right)^{1/2} 
    \tanh \left[ \frac{J}{T} \left( (1 - g z)\left(1 - \frac{g}{z} \right) \right)^{1/2} \right]
\end{align}


In the limit where T = 0, then the expression for $\tilde{D}$ reduces even more to just 

\begin{equation}
    \tilde{D} = \left( \frac{1-gz}{1-g/z} \right)^{1/2}
\end{equation}

The structure above can be used when you are calculating more complicated objects, which I will derive now.

First, let's recognize that we can write 

\begin{equation}
    \sigma^x_{j} = (c^\dagger_j + c_j) \prod_{n=0}^{j-1} \sigma^z_n = A_j J(0,j-1)
\end{equation}

The $J(i,j)$ are the jordan-wigner strings connecting sites $i$ and $j$. It can be easily seen that they have the property $$J(i,j) J(i,k) = J(j+1,k)= \prod_{w=j+1}^{k} iB_{w}A_{w}$$ 


From this, we can see that a general $n$-point function (assuming $n$ is even) is simple. For example, the 4 point function:

\begin{equation}
    \braket{\sigma^x_0 \sigma^x_{n_1} \sigma^x_{n_2} \sigma^x_{n_3}} = \braket{B_0 J(1,n_1-1)A_{n_1} B_{n_2} J(n_2+1,n_3-1) A_{n_3} }
\end{equation}

The structure of this correlation function generalizes to higher $n$ (assuming $n$ is even). Computationally, n point functions can be made even simpler remembering 

$$[\sigma^x_j,\sigma^x_k]= \delta_{j,k}$$ and $$(\sigma^x_j)^2=1$$

Which means we can always rearrange a 4 point function to be arranged from lowest to highest in index, then we can compute correlation functions in the form of connecting two two spins at a time.

If $n$ is odd we need to use cluster decomposition, and we can only recover the magnitude of the correlation function (sign information will be lost).The result generalizes trivially from the 1-point function:

\begin{equation}
    |\braket{\sigma^x_j}| = \lim_{d\to \infty} |\braket{\sigma^x_j \sigma^x_{j+d}}|
\end{equation}.

In typical canon, the 2-point functions are calculated using Pfaffians of Toeplitz Matrices. The Pfaffian of a matrix $\mathbf{A}$ has the property that 

\begin{equation}
    \text{PF}(\mathbf{A}) = \sqrt{\text{det}(\mathbf{A})}
\end{equation}

However, when you have more complicated correlation (for example, a corrleation function like $\braket{\sigma^x_{0}\sigma^x_{3} \sigma^x_{5} \sigma^x_{6}}$) function the resulting matrices cannot be properly determined via Toeplitz matrices, which is a shame because constructing them is very quick. 

Instead, we can construct the matrix by iterating over 2 point functions.

\subsection{Explicit Example}

Consider the correlation function 

$$\braket{\sigma^x_{0}\sigma^x_{2} \sigma^x_{5} \sigma^x_{6}} = \braket{\mathbf{B_0} A_1 B_1 \mathbf{A_2} \mathbf{B_5} \mathbf{A_6}  }$$

I have bolded the "endpoints" of strings to emphasize the form. In a gaussian free theory like the TFIM correlation functions like above can be solved via wick contractions. The Pfaffian of the matrix formed via elements of the wick contraction is an efficient way of doing this. 

\begin{equation}
    \braket{\sigma^x_{0}\sigma^x_{2} \sigma^x_{5} \sigma^x_{6}} = 
    \det{
    \begin{pmatrix}
        \braket{B_0A_1} && \braket{B_0 A_2} && \braket{B_0 A_6} \\
        \braket{A_1 B_1} && \braket{B_1 A_2} && \braket{B_1 A_6} \\
        \braket{ A_1 B_5} && \braket{A_2 B_5 } && \braket{B_5 A_6}
    \end{pmatrix}}
\end{equation}

We can see that because all quantities like $\braket{A_i A_j}=\delta_{ij}$ we can simply ignore these terms.
